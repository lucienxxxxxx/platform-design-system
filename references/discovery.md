# Discovery, evidence and synthesis

Capture product/URL, owner, audience, jobs, success criteria, platforms and regions, languages, supported devices, brand guidelines, repositories, design files and release constraints. Define reproduction, extension or inspiration, and whether the deliverable is an audit, pilot, code, Figma, or a shared library. Distinguish user-provided facts from research and hypotheses. Public visibility does not itself grant rights to reuse a logo, font, image, video or model.

Select representative high-value journeys, including a functional task where in scope. Record URL/path, screen size, element, state, input, observed behavior, evidence link/date and confidence. Examine mobile and desktop, content density, hover, keyboard focus, active, open, loading, empty, error, disabled and success where possible. Static HTML or a screenshot does not prove hidden behavior.

Derive 3–5 testable principles from evidence and classify each rule as observed, inferred or new. Identify palette, type, spacing, radii, imagery, layout and tone; map raw values to semantic roles and component tokens. Test direction across marketing and operational tasks. Include script coverage and font licensing, modes and contrast pairs as required. Record gaps, decisions, ownership and pilot acceptance criteria using `assets/templates/`.
