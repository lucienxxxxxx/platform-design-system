# Verification and governance

- Review rendered output at agreed desktop, tablet and mobile sizes; record browser, dimensions, date and evidence. Inspect long text, localization, zoom/reflow and media failure where relevant.
- Exercise keyboard, pointer and touch where available; inspect names, focus entry/return, visible focus and screen-reader behavior as feasible. Test empty, loading, error, offline, success and disabled states and real workflows when in scope. Mark untested items explicitly.
- Check actual text and non-text contrast using the applicable standard, including transparency and overlays. The bundled script only checks solid opaque hex colors, not accessibility as a whole.
- Check reduced motion, content access without hover, performance, project tests/build and actual preview interactions. Automated tools do not replace manual testing.
- Deliver requested artifacts with sources, provenance, token mappings, use guidance, verification evidence, unresolved issues and limitations. For shared systems specify ownership, source of truth, versioning, review, migration, deprecation and release process. Do not claim publication, upstream installation or Figma synchronization unless performed.
