# Delivery checklist

- [ ] Scope, users, journeys and requested deliverables documented.
- [ ] Evidence and observed, inferred, proposed decisions distinguished.
- [ ] Asset provenance and use recorded; tokens and mappings documented.
- [ ] Priority component states and accessible interactions specified.
- [ ] Full-system output includes an interactive component gallery, unless the user narrows scope.
- [ ] Actual gallery and other deliverables inspected in context and at target sizes.
- [ ] Keyboard, touch alternatives, focus, reduced motion and contrast checked as applicable.
- [ ] Loading, empty, error, offline and long-content cases checked as applicable.
- [ ] Project tests/build run; evidence, issues, owners and limitations reported.
- [ ] Handoff and maintenance process documented for a shared system.
